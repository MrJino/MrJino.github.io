02 / INTERFACE

INTERFACE.

일관된 화면과 상호작용을 만드는 UI 설계 기준을 정리합니다.

01

MODAL · LAYOUT

편집 팝업

  1. 01

    헤더 영역은 스크롤 영역에서 제외하고 아래에 구분선을 추가합니다.

  2. 02

    하단 버튼 영역은 스크롤 영역에서 제외하고 위에 구분선을 추가합니다.

  3. 03

    편집 팝업의 하단 버튼 영역 왼쪽에 삭제 버튼을 제공합니다.

  4. 04

    모든 삭제 과정은 반드시 사용자에게 확인 팝업을 먼저 보여준 뒤 진행합니다.

02

MODAL · CONFIRMATION

확인 팝업

  1. 01

    팝업 왼쪽영역에 상황에 맞는 아이콘을 보여줍니다.

  2. 02

    확인 팝업은 440px 폭, 42px 아이콘, 20px 제목, 40px 버튼 규격을 사용합니다.

03

CONVERSATION · INPUT

대화형 팝업

  1. 01

    하단 입력란은 항상 최대 1줄로 제한합니다.

  2. 02

    2줄 이상 입력이 필요한 경우에는 별도의 팝업을 띄어 입력을 받습니다.

  3. 03

    텍스트 입력이 필요한 단계에서는 포커스가 입력란에 가도록 합니다.

  4. 04

    입력한 내용을 확인하는 마지막 단계에서 엔터키를 입력하면 입력한 내용을 저장하고 팝업을 닫습니다.

  5. 05

    드롭다운 선택 옵션일 경우 첫 번째 항목이 기본값으로 설정되어 있도록 합니다.

  6. 06

    하단 입력란에는 별도의 부가 설명란을 보여주지 않습니다.

04

NOTIFICATION · FEEDBACK

사용자 알림

  1. 01

    ‘의견이 접수되었습니다.’ 등의 간단한 사용자 알림은 별도의 알림 영역을 만들지 않고 스낵바 형태로 보여줍니다.
